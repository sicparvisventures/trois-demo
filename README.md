# Trois — speelbare demo

Een mobile-first kaartspel voor 2–4 spelers. Variant van de Shithead/Palace-familie
met een eigen set special cards.

**▶ Speel:** https://sicparvisventures.github.io/trois-demo/

Zet hem op je beginscherm (iOS: deel → *Zet op beginscherm*) — dan speelt hij als een
echte app en werkt hij ook offline.

## De regels in het kort

Je krijgt 9 kaarten: **3 blind** op tafel, **3 open** erbovenop, **3 in je hand**.
Leg een kaart die gelijk of hoger is dan de bovenste, of pak de hele stapel.
Wie als eerste al zijn kaarten kwijt is, wint. De laatste is *de Trois*.

| | |
|---|---|
| **2** | reset — mag altijd, daarna mag alles |
| **3** | onzichtbaar — de kaart eronder blijft gelden |
| **6** | drie 6'en op de stapel = burn |
| **7** | de volgende moet 7 of lager |
| **8** | de volgende slaat over |
| **9** | de richting draait om |
| **10** | burn — stapel weg, jij speelt opnieuw |
| **4×** | vier dezelfde bovenop = burn |

De **4 is de laagste** kaart; 2, 3 en 10 staan buiten de rangorde.
